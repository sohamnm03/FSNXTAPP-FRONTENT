## Naming gate

```
NAMING: ZFS_CE_TrmFxTP -> matches CDS "Custom entity ZFS_CE_<Entity>", <Entity> = TrmFxTP (transactional, TP once)
NAMING: ZFS_CE_TrmFxTP (BDEF) -> matches "Behavior definition: same as root view"
NAMING: ZCL_FS_TRM_FX_QUERY -> matches ABAP OO "RAP query provider ZCL_FS_<AREA>_<NAME>_QUERY", AREA = TRM
NAMING: ZBP_FS_TRMFXTP -> matches "Behavior implementation class ZBP_FS_<Entity>" (upper case)
NAMING: LHC_TRMFX / LSC_TRMFX -> match "Behavior handler LHC_<Entity>" / "Saver LSC_<Entity>" (TP stripped, L-226)
NAMING: ZFS_SD_TRMFX -> matches "Service definition ZFS_SD_<Entity>" (TP stripped)
NAMING: ZFS_SB_TRMFX_O4_API -> matches "Service binding ZFS_SB_<Entity>_<O4>_<API>" (19 chars, under the 26 cap)
```

Routing: DDLS, SRVD and CLAS are created via `mcp-abap-abap-adt-api createObject` + transport. This is
the L-546 fallback: `adt-mcp` cannot put a DDLS/CLAS on a named transport reliably. BDEF and SRVB are
created via `adt-mcp` with top-level `transportRequestNumber` (L-564).

## Service

`/sap/opu/odata4/sap/zfs_sb_trmfx_o4_api/srvd_a2x/sap/zfs_sd_trmfx/0001/FxTransaction?sap-client=100`
- **Filterable/sortable (CTE columns):** CompanyCode, FinancialTransaction, ProductType, TransactionType,
  Partner, ValuationClass, Portfolio, ActiveStatus.
- **Not filterable** (BAPI-only fields, refused with HTTP 500): amounts, currencies, rates, dates,
  ActivityCategory.
- **POST:** send currencies, lead/follow, `TradedCurrency` and the amount **in the traded currency**
  only; the other amount is computed.
- **PATCH:** amounts, value date, rates, contract date, valuation class, portfolio. Create-only fields
  are ignored (Core.Immutable).
- **Settle:** `POST …/FxTransaction(CompanyCode='…',FinancialTransaction='…')/com.sap.gateway.srvd_a2x.zfs_sd_trmfx.v0001.Settle`,
  body `{}`. ActivityCategory 20 → 30.
- **DELETE:** reverses the latest activity (reason 04). A settled deal needs two DELETEs.
