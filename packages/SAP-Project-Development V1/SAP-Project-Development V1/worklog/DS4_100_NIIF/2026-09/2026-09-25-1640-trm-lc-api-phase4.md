## Service

`/sap/opu/odata4/sap/zfs_sb_trmlc_o4_api/srvd_a2x/sap/zfs_sd_trmlc/0001/LetterOfCredit?sap-client=100`
- **Filterable/sortable (CTE columns):** CompanyCode, FinancialTransaction, ProductType, TransactionType,
  Partner, ValuationClass, Portfolio, Currency, StartTerm, EndTerm, ActiveStatus. `$orderby` always
  closes with the keys, so paging is stable.
- **Not filterable** (BAPI-only fields, HTTP 500): Amount, FlowType, LcNumber, parties/banks,
  PlaceOfExpiry, PaymentTerm, TerminateDate, LastPresentation*, ActivityCategory.
- **POST:** the mandatory fields are CompanyCode, ProductType, TransactionType, Partner, Currency,
  StartTerm, EndTerm and Amount. The source deal's FlowType (1860), beneficiary, valuation class and
  payment term were copied into every test deal. Currency, Partner and product/transaction type are
  create-only (Core.Immutable).
- **Actions** (bound, `com.sap.gateway.srvd_a2x.zfs_sd_trmlc.v0001.<Name>`):
  - `Settle`: body `{}`; cat 20 → 30.
  - `Terminate`: body `{"TerminateDate":"yyyy-mm-dd"}`. It needs a settled contract (T1 221
    otherwise); cat → 80. There is no inclusive flag: the BAPI ignores it (L-587).
  - `Present`: body with **all 12 parameters** (Nullable=false): ActionType (CREA/CHGE/DELE/ACCP/
    REJE/ACPS/SETT/SEND/SDRA/RVER), PresentationItem, FlowType (e.g. 1840), PresentationBank,
    ShipmentDate, PresentationDate, PaymentDate, PresentationAmount, PresentationCurrency,
    Discrepancy, DiscrepancyAmount, DiscrepancyCurrency. **Currently blocked by an SAP dump (L-586).**
    A field reaches the BAPI only when non-initial, so a CHGE cannot clear a field (review I4,
    accepted while Present is blocked).
- **Non-LC keys:** refused by the BAPI itself with FTR_LC 107 (L-587).
- **DELETE:** reverses the latest activity. A settled deal needs 2 DELETEs; a settled and terminated
  deal needs 3.
