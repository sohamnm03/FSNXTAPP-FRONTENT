## Scope

Every ALM app application wired to a SAP report service, for 1000 / 2025 / 10, **read-only**: no Save, Lock or Delete, no
manual-data write. Two layers:

- **A · App vs SAP API:** each report read through a temporary app instance (own port, current code, live SAP; 8093 untouched)
  and compared field by field with a direct read of the same SAP OData service.
- **B · SAP API vs SAP sources:** API figures checked against independent SAP reads (DB via `scripts/adt-sql.ps1`, original
  `/FS00/` reports where cheap), so a match in layer A is not just the app echoing a wrong API.

Reports in scope (from `config/catalog.mjs`): TRM Repayment Cashflows ALM1 (`trmrepay`), Quarterly ALM1 Report (`qtrreport`
alm1), TRM Accrual Cashflow / TRM Principal O/S ALM 2,3 (`trmdata`), GL Account Details / GL Account Balance Details
(`tbdata`), Structural Liquidity Report (alm2), Interest Rate Sensitivity Report (alm3), Update Manual Data ALM 1/2/3 (read
view only). Placeholders without a service (Maturity Profile, Structural Gap, Repricing Profile, Rate Scenarios, Budget
Details, Cash Flow Forecast Preview) are out of scope.
