Allow-list entry · ZFS_T_DYN_REG

Target
A kind and a name together decide what an action may use — a row registered TABL is refused by RunQuery, whose own step kind is QURY (L-526).
Permissions
Clearing Active is an instant kill switch — it takes effect on the next call and needs no transport.
Execution
0 means “this target sets no override”, never “unlimited” — the framework's own budget still applies.
Generation
One object per registry row, by design — a delimited list in a char120 reads as maintained while silently granting more than intended (the ZDYNTGT trap, L-441). A target needing two number-ranged fields is a documented limit.
